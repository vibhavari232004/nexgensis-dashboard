Nexgensis Product Dashboard

A React-based product dashboard developed as part of the Nexgensis Technologies React Assessment.

Features

- User Login and Logout
- Product Dashboard using DummyJSON API
- Search products with debounce
- Filter products by category
- Sort products
- Pagination
- View product details
- Add, Edit, and Delete products

Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router
- Lucide React
- DummyJSON API

Installation

Clone the repository:

    git clone https://github.com/vibhavari232004/nexgensis-dashboard.git

Navigate to the project folder:

    cd nexgensis-dashboard

Install dependencies:

    npm install

Start the development server:

    npm run dev
